# 0_STAGING — the temporary file

Information that deserves filing but has no time, focus or attention this moment is appended here the
moment it is noticed, then landed into the level file that owns it and deleted. Nothing in flight goes
unrecorded, and nothing stays here once it has a home: this file reads as the list of what is currently
unfiled, not as a diary.

It is not zoned by source tier. An entry that has reached a tier is ready to leave.
